# 用户使用指南

## 第一次启动

1. 下载并解压发布 ZIP。不要直接在压缩包预览窗口内运行程序。
2. 双击 `MediaDupFinder.exe`。
3. Windows SmartScreen 若提示“Windows 已保护你的电脑”，这是未购买代码签名证书的开源软件常见提示。确认文件来自项目官方 Release 后，可点击“更多信息”查看发布者和文件名，再决定是否运行。

## 扫描

1. 点击“批量添加目录”：
   - 盘符列表支持直接多选，无需按住 `Ctrl`；也可以点击“选择全部固定磁盘”。
   - 普通文件夹可以在同一个窗口内连续加入，最后统一确认。
   - 还可以从资源管理器复制多个目录的路径，按每行一个粘贴；英文引号会自动去除。
   - 已经存在的目录和本次重复选择会自动去重；不可访问的空光驱或离线盘会提示并跳过。
2. “包含子目录”默认开启。
3. “作品识别”建议先用“严格作品识别（推荐）”：
   - 严格作品识别：优先减少误报，推荐用于正式整理。
   - 标准作品识别：允许更多轻微拼写差异。
   - 兼容轻微拼写差异：召回更多标题拼写变体，需要更仔细复核；明确的日期、编号、季集或分段冲突仍会被隔离。
4. 类型默认是“视频文件”。选择“自定义扩展名”后，可填写 `mp4;mkv;vob;m2ts` 这类列表；只有确实要整理所有类型时才切换“全部文件”。
5. “忽略小于”可以填写任意非负 MB 数值，例如 `50`、`100` 或 `500`：
   - 小于该大小的文件不会进入作品解析、候选比对或 MD5 读取。
   - `0` 表示不限制；恰好等于阈值的文件仍会扫描。
   - 整理长电影时可从 50–200 MB 开始；短视频库应使用更小阈值，避免漏掉需要的作品。
6. “最大文件”同样使用 MB，`0` 表示不限制；设置非零值后，大于该值的文件会提前跳过。最大值不能小于“忽略小于”的最小值。
7. 点击“管理排除目录”，可以批量加入不希望扫描的缓存、临时下载或私人目录。每个排除目录的全部子目录都会跳过；可随时移除或清空。
8. “比对范围”提供四种方式：
   - 全部文件互相比对：默认方式，最完整。
   - 只比较不同所在目录：适合寻找散落在不同文件夹中的副本，并忽略同一文件夹内部比较。
   - 只比较同一所在目录：适合逐文件夹清理，不跨文件夹合并候选。
   - 只比较不同扫描根目录/盘符：适合比较两个备份盘或两个单独加入的根目录。
9. “启用作品身份比对”默认勾选。取消后只运行所选 MD5 通道，适合只寻找内容字节完全相同的文件。作品身份和 MD5 不能同时关闭。
10. 其他过滤选项：
   - “跳过隐藏/系统文件与目录”适合扫描整个盘符，可避开回收站、系统目录和隐藏缓存。
   - “跳过临时或未完成下载文件”会过滤 `.part`、`.crdownload`、`.tmp` 等文件。
   - “排除文件名关键字”支持逗号、分号或换行分隔，例如 `sample; trailer; 预告; 花絮`；只要文件名包含任一关键字就会跳过。
11. MD5 默认选择“智能扫描（推荐）”：
   - 关闭 MD5：只做作品身份和可选视频信息识别，速度最快。
   - 智能扫描：同大小预筛后，大文件只读取开头、中间、结尾各 1 MB；快速指纹相同才计算完整 MD5。
   - 完整扫描：对全部同大小候选进行完整 MD5 校验，适合希望彻底检查且可以等待的情况。
12. 点击“开始扫描”。扫描阶段不会改名、移动或删除任何文件。

目录读取时会显示已经保留和按设置过滤的文件数量。完成后摘要列出过小、过大、非目标类型、排除目录、隐藏/系统项、临时文件和关键字排除等原因。若启用了作品身份比对，软件随后依次显示“解析作品身份”“生成同作品候选”“核对作品身份”和“整理同作品候选组”。身份核对阶段会显示候选比对总数、已完成数量、剩余数量、处理速度、已用时间、预计剩余时间以及当前核对的两个文件名。总数是经过身份索引与所选范围筛选后真正需要比较的候选对数，并不是把所有文件盲目两两组合。预计时间需要先积累少量处理数据，刚进入新阶段时短暂显示“计算中”属于正常情况。点击“停止”可在这些阶段安全结束本次扫描，不会修改任何文件。

MD5 模式在点击“开始扫描”前就已经确定。开始后程序会按所选模式自动运行到底，不会在扫描中途弹窗等待点击。唯一大小的文件不会进行哈希读取；智能模式会先用三段快速指纹排除大部分不同内容，从而避免不必要的完整读取。

哈希期间底部会显示当前阶段、读取百分比、已读容量、速度和预计剩余时间。已经计算过的 MD5 会保存在本机缓存中；下次复用前仍会重新检查文件状态和快速指纹。

## 检查候选组

左侧每行是一组候选文件，“身份/依据”会显示作品编号、系列日期单集、季集编号、影视标题、完整 MD5 或身份 + MD5，并显示数量、精确 MD5 子组数、估计可释放空间、组内时长差和最低匹配置信度。右侧显示组内文件：

- 文件名、识别出的作品名、身份类型、身份来源、分段和完整目录
- 文件大小和格式
- 分辨率、时长、修改时间
- 视频编码
- MD5（智能模式下只为快速指纹相同者及小文件生成；完整模式覆盖全部同大小候选）
- 内容关系：直接标明“MD5 相同 ×N”“MD5 已验证但组内不同”“快速指纹不同”或“作品身份相似、内容未确认”
- 当前决定与重点复核提示

左、右两侧都可以点击任意列标题排序，再次点击会切换升序/降序。大小、时长、分辨率和修改时间使用真实数值排序，不会按显示文字排序；尚未读取到的时长或分辨率始终放在末尾。点击表格旁的“列顺序”，可选中任意列并向左/向右移动；布局会自动保存。也可以使用底部横向滚动条查看完整列。双击一行，或点击“在资源管理器中查看”，可以定位原文件并手工播放检查。

### 如何理解“作品身份”

软件不是拿文件名前几个字符做相似比较，而是先判断名称属于哪一种身份：

- 作品编号：`MIDA-630`、`FC2-PPV-1234567` 等；编号不同直接隔离。
- 日期单集：`brothalovers.15.07.28.lynna.nilsson`；系列相同但日期不同仍是不同作品。
- 系列连续编号：`fellatiojapan567`、`Japanese amateur leak (12)`；系列相同但编号不同直接隔离。
- 季集编号：`The.Show.S02E07`、`The.Show.E07`、`纪录片.第12集`；集号不同直接隔离。
- 影视标题：去掉画质、编码、网站和宣传词后比较实际标题；共享系列词但人物名、单集名等实质词语不同不会合并。

`2048社区 - fun2048.com@fc1298546` 中，`2048社区` 与域名属于站点包装，`fc1298546` 才是保留用于判断的唯一标识。`www.98T.la@` 也会作为广告域名删除，但后面的系列编号保留。`KAVR-253-2` 与 `KAVR-253-8` 会被识别成同一番号的不同分段，因此不会作为可互删候选；长描述末尾的 `_1/_2/_3/_4` 同样保留为分段。`VD-1080`、`HD-720` 只表示画质。`015` 或 `ck` 这类证据不足的短标签不会单独形成作品候选组。

`VTS_01_1.VOB`、`VIDEO_TS.VOB`、`BDMV/STREAM/00001.M2TS` 这类文件名本身不含作品名称。程序只在这些明确场景下查看路径，跳过 `VIDEO_TS/BDMV/Disc1` 等容器目录，使用最近的有效上级影片目录作为作品身份，并把 VTS/流编号保留为分段。右侧“身份来源”会明确显示“上级影片目录”，方便人工核对。

若一个名称候选同时碰到多组不同的完整 MD5，程序会把每个 MD5 精确重复组独立保留，不允许名称结果把它们传递合成一个大组。右侧“内容关系”应作为删除前的重要复核依据。

在任意文件行上点击鼠标右键，可以：

- 查看完整文件信息
- 直接打开文件
- 在 Windows 资源管理器中选中文件
- 打开 Windows 文件属性
- 复制一个或多个文件的完整路径或文件名
- 直接设置保留、标记删除或撤销标记

“查看完整文件信息”窗口会集中显示完整路径、精确字节数、文件状态、修改/创建/访问时间、分辨率、时长、编码、完整 MD5、组内内容关系、身份来源、名称归一化结果、匹配原因、置信度和重点复核提示。窗口中的“复制全部信息”适合在反馈误识别问题时使用。

## 做出决定

- “设为保留”：一组内选择一个明确需要留下的文件。
- “标记删除”：可多选；软件会阻止把整组全部标记删除。
- “撤销标记”：恢复为未决定。
- “当前组智能选择”：按分辨率、封装格式和大小给出建议。
- 菜单“操作 → 全部组智能选择”：一次标记全部候选组，但仍不会执行删除。

智能选择只是建议。例如，同为 1080P 时，大文件未必一定更好；不同剪辑版、配音版、字幕版也可能都值得保留。如果读取到的片长差异超过 3% 且超过 30 秒，智能选择只建议一个保留项，不会自动把其他文件标记删除。

## 执行删除

1. 检查所有红色“删除”标记。
2. 点击“执行已标记删除”。
3. 阅读文件数量、总大小、预览清单和片长差异警告。
4. 再次确认后，文件才会进入 Windows 回收站。

程序不提供批量永久删除按钮。需要恢复时，请立即打开 Windows 回收站。网络共享路径因无法保证可恢复，会被拒绝。

## 读取真实分辨率

没有 `ffprobe.exe` 时，软件仍可正常工作，但只会根据文件名中的 `4K`、`2160P`、`1080P` 等标签推测分辨率。

如需读取媒体内部信息，把兼容系统的 `ffprobe.exe` 放在主程序同一目录，重启后勾选“读取候选视频分辨率”。详细说明见项目 `tools/README.md`。

## 导出报告

点击“导出报告”可保存 CSV。文件使用 UTF-8 BOM，中文 Windows 上可直接用 Excel 打开。报告包含候选作品、身份类型、身份来源、作品身份键、作品编号、分段、日期/季集、匹配原因、MD5、内容关系、时长、编码、片长保护提示、置信度、决定、完整路径、大小和分辨率，可作为删除前审核记录。
