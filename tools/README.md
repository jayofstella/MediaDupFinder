# 可选：启用真实视频分辨率读取

软件本身不依赖第三方运行库，可以直接扫描并按解析出的作品身份分组。若希望读取视频内部记录的真实分辨率、时长和编码，可自行准备与目标 Windows 版本兼容的 `ffprobe.exe`：

1. 将 `ffprobe.exe` 放在 `MediaDupFinder.exe` 同一目录，或者放入其旁边的 `tools` 文件夹。
2. 重新启动软件，勾选“读取候选视频分辨率”。
3. 软件只会对已经筛出的候选视频运行 ffprobe，不会逐个解析全部文件。

本仓库不内置 FFmpeg/ffprobe 二进制文件，因此没有把第三方体积和许可证义务混入主程序。发布者若自行分发 ffprobe，应同时遵守所选 FFmpeg 构建版本的许可证。
