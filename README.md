# MediaDupFinder（影视作品去重助手）

一个面向 Windows 的本地桌面工具：先从文件名中解析作品编号、日期单集、季集编号或影视标题，再比较“作品身份”；同时用“文件大小 + 完整 MD5”寻找字节完全相同的副本。软件不会仅因两个文件拥有相同前缀就把它们判为同一作品。

例如，下列文件会被归入同一候选组：

- `MIDA-630.mp4`
- `MIDA-630-C.mp4`
- `MIDA-630-4k.mov`

下列中文片名也会被识别为同一候选作品：

- `寒战.mp4`
- `寒战1.mp4`
- `经典剧情《寒战1》.mp4`

下列名称会被明确隔离，不会作为可互删的同作品候选：

- `brothalovers.15.07.28.lynna.nilsson.mp4` 与 `brothalovers.15.04.02.rachel.rayye.mp4`（同系列、不同日期作品）
- `KAVR-253-2.mp4` 与 `KAVR-253-8.mp4`（同作品、不同分段）
- `2048社区-fun2048.com@fc1298546.mp4` 与 `2048社区-fun2048.com@fc1356110.mp4`（站点前缀相同、唯一编号不同）
- `www.98T.la@fellatiojapan567.mp4` 与 `www.98T.la@fellatiojapan568.mp4`（广告前缀相同、系列单集编号不同）
- `Japanese amateur leak (1).mp4` 与 `Japanese amateur leak (10).mp4`（同系列、括号单集编号不同）

## 已完成的功能

- Windows 7 SP1、Windows 10、Windows 11 兼容技术路线
- 批量添加扫描位置：一次多选多个磁盘盘符，也可累计选择文件夹或粘贴多行路径
- 默认扫描 17 类常见视频，也可切换为自定义扩展名或全部文件
- 可同时填写最小与最大文件大小；不在范围内的文件会在作品解析和 MD5 读取前直接过滤，`0` 表示不限制
- 可批量管理排除目录，所选目录及其全部子目录不会进入扫描
- 可选择全部文件、仅不同目录、仅同一目录或仅不同扫描根目录/盘符之间进行比对
- 作品身份通道可单独关闭，以执行仅 MD5 的字节级查重
- 可选跳过隐藏/系统项、临时或未完成下载文件，并可用多个文件名关键字排除样片、预告等内容
- 识别 `MIDA-630`、`FC2-PPV-1234567`、1PONDO、Tokyo-Hot、字母数字混合前缀等作品编号
- 统一番号前导零，例如 `ABC-001` 与 `ABC-1`
- 去除网站域名、站点品牌、发布组、`4K`、`BluRay`、编码、字幕、语言和复合标签，同时保留站点包装后的唯一作品编号
- 繁简体匹配、罗马数字序号转换、英文标题词序变化匹配
- 年份安全规则：单侧年份可匹配，双侧不同年份不合并
- 识别 `YY.MM.DD`、`YYYY.MM.DD`、`YYYYMMDD` 日期单集，以及 `S02E07`、`2x07`、`E07`、`第12集` 等季集形式
- 识别 `fellatiojapan567` 等“长系列名 + 连续编号”，以及 `Japanese amateur leak (12)` 等括号单集编号
- 同系列不同日期、同剧不同集、不同番号、不同分段和短纯数字标签均执行隔离保护
- `VD-1080`、`HD-720` 等只作为画质信息，不再误当作品编号或作品名
- `VTS_01_1.VOB`、`00001.M2TS` 等光盘通用文件名改用最近的有效上级影片目录识别作品，同时保留光盘段号
- 普通影视标题只允许标题相同、词序调整或逐词轻微拼写差异；共享系列前缀不能单独构成匹配
- 作品身份解析分阶段显示索引、候选生成、身份核对和分组进度
- 身份核对显示总数、已完成/剩余数量、速度、已用时间、预计剩余时间和当前文件
- MD5 提供关闭、智能、完整三档；默认智能模式只处理同大小候选
- 大文件先读取开头/中间/结尾各 1 MB，快速指纹相同后才计算完整 MD5
- 本地缓存已验证的 MD5，复用前重新核对文件状态和快速指纹
- MD5 模式在扫描前一次选定，扫描过程中不会再弹窗等待用户确认
- 哈希阶段显示真实读取容量、吞吐速度和预计剩余时间
- 合并作品身份与 MD5 时把每个精确 MD5 组作为独立边界；弱名称规则不能再把多组不同内容串成危险大组
- 主动区分 `CD1/CD2`、`Part1/Part2`、番号后的数字段号及 `A/B` 段
- 逐组手动设置“保留 / 删除 / 未决定”
- 按“分辨率 → 格式 → 文件大小”提供智能保留建议
- 可选读取视频真实分辨率、时长和编码（需要外置 `ffprobe.exe`）
- 片长差异超过 3% 且超过 30 秒时标为重点复核，并禁止智能批量标记删除
- 候选组及组内文件支持点击所有列标题排序；大小、时长、分辨率、修改时间按真实数值排序，未知值固定置后
- 两张结果表都支持自定义列顺序，任意列可向左或向右移动并自动保存
- 结果表直接展示识别作品、身份类型、身份来源、分段、MD5 子组、内容关系、大小、时长、编码和目录等信息
- 文件结果右键菜单支持完整信息、打开、资源管理器定位、Windows 属性和复制路径
- 完整信息窗口集中展示文件系统、媒体、MD5、名称解析及候选组判定信息
- 删除前二次确认；不提供静默永久删除，Windows 下默认进入回收站
- 阻止把同一候选组全部标记删除
- 导出带 BOM 的 CSV 报告，可直接用 Excel 打开
- 可直接导入 v1.7.0 导出的 CSV，恢复数百个“保留 / 删除 / 未决定”标记，无需重新扫描或逐个重做选择
- 执行删除时逐文件校验；已移动、修改、删除或不再安全的项目自动标为“忽略”，其余有效标记继续执行
- 自动生成带原因、原路径、扫描快照和当前状态的忽略清单；若保留文件已经失效，则让用户选择仅本组继续、本次全部继续、安全忽略本组或取消操作
- 后台扫描和停止按钮；目录扫描、作品身份比较和候选整理阶段均可停止
- 自动保存窗口、目录和扫描偏好；记录回收站操作历史
- GitHub Actions 自动构建 Windows x64 与 x86 发布包

## 直接使用

发布版用户只需要：

1. 下载与你系统匹配的 ZIP。多数电脑选择 `Windows-x64`；32 位 Windows 7 选择 `Windows-x86`。
2. 解压整个 ZIP。
3. 双击 `MediaDupFinder.exe`。
4. 批量选择一个或多个磁盘/目录并开始扫描。
5. 逐组检查，设置保留和删除，再执行回收站操作。

如果已经在 v1.7.0 中完成大量标记，可在新版本点击“导入旧报告”，直接载入原 CSV 后继续执行，不需要重新扫描或重新标记。

> Windows 7 必须是 SP1。极精简或长期未更新的 Windows 7 可能缺少 Universal C Runtime，此时需要先安装微软 Visual C++ 2015–2022 Redistributable 或相应系统更新。Windows 10/11 通常已具备所需运行组件。

更细的操作步骤见 [用户使用指南](docs/USER_GUIDE.md)。

## 从源码运行

运行环境只需要 Python 3.8 或更高版本，运行时没有第三方 Python 依赖。

Windows 用户可以双击：

```text
run_from_source.bat
```

也可以直接双击 `MediaDupFinder.pyw`。

也可在终端运行：

```powershell
$env:PYTHONPATH = "src"
python -m media_dup_finder
```

## 构建 Windows EXE

为了兼容 Windows 7，构建环境固定为：

- Python 3.8.x（推荐 3.8.10）
- PyInstaller 5.13.2
- Tkinter / Tcl-Tk 8.6

Windows 上安装 Python 3.8 后，双击 `build_windows.bat`。脚本会自动创建隔离环境、运行测试、生成 EXE 和 ZIP：

```text
dist\MediaDupFinder.exe
release\MediaDupFinder-v1.8.0-Windows-x64.zip
```

PyInstaller 不是交叉编译器，因此 Windows EXE 必须在 Windows 或 GitHub 的 Windows Runner 上生成。完整说明见 [Windows 构建与发布](docs/WINDOWS_BUILD.md)。

仓库已经带有 `.github/workflows/build-windows.yml`：


## 识别逻辑概览

程序只把结果称为“候选组”，不会断言文件一定相同：

1. 先按文件类型、最小/最大大小、排除目录、隐藏/系统属性、临时状态和自定义关键字过滤，并应用所选比对范围。
2. Unicode、大小写、繁简体和尾部罗马数字归一化，并清理画质、编码、站点包装等非作品信息。
3. 按强度依次解析日期单集、系列连续编号、季集编号、作品编号和普通影视标题；光盘通用名只在必要时读取上级影片目录。
4. 日期、季集、作品编号、发行年份或分段任一明确冲突时直接隔离，不再用前缀相似度覆盖冲突。
5. 普通标题只允许精确别名、词序调整或逐词轻微拼写差异；不同实质词语不会因共享系列名而合并。
6. MD5 智能模式对同大小文件先计算三段快速指纹，只对指纹相同者读取完整内容；完整模式则校验全部同大小候选。
7. 合并启用的识别通道，对连锁匹配再次按锚点拆组；不同完整 MD5 组之间禁止被名称结果传递串联。
8. 读取到视频时长后，为超过安全范围的片长差异组增加保护，不自动建议删除。

详细规则与边界见 [算法说明](docs/ALGORITHM.md)。

## 安全边界

- 扫描和分组阶段是只读操作；MD5 只在本机顺序读取文件。
- 智能选择只做标记，不会自动执行删除。
- 同一组不能全部标记删除。
- Windows 删除使用带撤销能力的系统回收站接口。
- 为避免网络共享文件被不可恢复删除，UNC 网络路径会被拒绝。
- 不跟随符号链接，也不处理目录。
- MD5 期间会检测文件变化；缓存复用前也会重新验证快速指纹，删除前再次检查大小和修改时间。
- 删除校验按文件独立执行，一个文件状态变化不会再中止整批操作；异常项目自动忽略并写入 CSV 清单。
- 如果某个候选组已经找不到状态正常的保留文件，软件会明确列出异常并询问；默认安全选项是忽略本组，也可由用户确认仅本组或本次后续同类情况继续执行。
- 片长差异较大的文件不会被“智能选择”自动标记删除。
- 软件完全本地运行，不上传文件名、路径或媒体内容。

作品身份识别仍是候选筛选，不等于内容完全相同。正式删除前仍应播放或打开关键文件进行人工确认，并保留重要数据的独立备份。
